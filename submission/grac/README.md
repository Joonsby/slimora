게임물관리위원회(GRAC) 등급분류 신청 화면에 첨부할 자료입니다. 작성일 2026-10-29.

**올리는 법** — 신청 화면의 「간소화 관련 첨부파일」 칸에 아래 4개 파일을 넣고 「전송하기」를 누릅니다.
이 `README.md` 는 올리지 않습니다. 칸의 한도는 최대 100개 · 5 GB 이고, 4개 합계는 29,102,589 bytes(약 27.8 MB)입니다.

**심사용 빌드 ZIP 구성**

```
README.txt          실행 방법 (한국어)
start-windows.bat   Windows 실행 — 아래 스크립트를 실행
start-server.ps1    이 PC 안에서만 접속되는 임시 웹 서버 (http://localhost:8080/, 설치 불필요)
web/                게임 빌드 (index.html, assets/)
```

- 게임 서버나 인터넷 연결은 필요 없지만, **정적 웹 서버로 열어야** 합니다. `web/index.html` 을 더블클릭(`file://`)하면 브라우저 보안 정책 때문에 실행되지 않습니다
- 앱인토스 업로드용 `.ait` 파일은 위원회 제출용이 아니라서 넣지 않았습니다

## 2. 만든 방법

| 산출물 | 방법 |
|---|---|
| 빌드 | 저장소 루트에서 `npm run build` → `client/dist` 를 `web/` 으로 복사. 기준 소스: 커밋 `255a425` + 커밋하지 않은 앱인토스 SDK 연동 변경. SDK 코드는 운영 번들에 들어가지 않으며, 게임 JS 번들(`index-DIMoqMRu.js`)은 SDK 연동 전과 같습니다 |
| 영상 · 스크린샷 | 설치된 Chrome(헤드리스)을 DevTools 프로토콜로 제어해 심사용 빌드를 실행. 저장 데이터가 없는 새 프로필에서 시작했고, 조작은 화면 버튼 좌표를 누르는 것뿐입니다. 게임 데이터 · 저장소를 조작하지 않았고 화면을 합성하지 않았습니다. 화면 프레임을 기록한 뒤 Chrome 의 WebCodecs 로 H.264 인코딩해 MP4 로 저장 |
| 설명서 PDF | 소스 분석 결과로 작성한 HTML 을 Chrome 으로 A4 인쇄 (글꼴: 맑은 고딕 임베드) |
| ZIP | .NET `ZipArchive` 로 생성. 경로 구분자 `/`, 한글 파일명은 UTF-8 표시 |

작업용 스크립트는 임시 폴더에서만 썼고 저장소에 남기지 않았습니다. 게임 소스는 바꾸지 않았습니다.

## 4. 검증하지 못한 항목

- **실제 휴대폰과 토스 앱(앱인토스) 안에서의 실행** — PC 의 헤드리스 Chrome 으로 390×844 세로 화면을 흉내 내 확인했습니다
- Safari · Firefox 등 다른 브라우저
- `start-windows.bat` **더블클릭** 실행 — 같은 스크립트를 명령으로 실행해 확인했지만, 탐색기에서 더블클릭했을 때의 동작과 Windows SmartScreen 경고 여부는 보지 못했습니다. 다른 PC 에서도 확인하지 않았습니다
- macOS · Linux 에서의 ZIP 해제 (규격 준수만 확인)
- 영상을 Windows 기본 플레이어 · 휴대폰에서 직접 재생해 보는 것 (디코딩만 확인)
- PDF 를 Adobe Acrobat 등 다른 뷰어에서 열어 보는 것
- 영상에 없는 장면 — 도전 실패 · 스테이지 5~6 · 특성 단계 상승. 소스로만 확인했습니다
- 위원회 신청 시스템의 허용 확장자 — 첨부 칸에 개수(100개) · 용량(5 GB) 한도만 표시되고 확장자 제한은 표시되지 않습니다

## 5. 심사 제출 전에 확인할 사항

1. **게임명 표기** — 설명서의 게임명은 「슬라임 용병단」(영문 표기 Slimora)입니다. 게임 화면(브라우저) 제목도 「슬라임 용병단」이라 코드는 바꾸지 않았습니다. 신청서의 게임물 명칭도 같게 적으세요. 파일 이름은 `Slimora_` 로 남아 있습니다
2. **심사용 웹 URL** — 비어 있던 URL 항목은 설명서에서 뺐습니다. 웹으로도 제공하려면 `web/` 폴더를 정적 호스팅에 올리고 주소를 신청서에 따로 적으세요
3. **ZIP 을 받아 주는지는 확인되지 않았습니다** — 첨부 칸에 확장자 제한 표시는 없지만, 실제로 올려 보기 전까지는 확실하지 않습니다
4. **영상 용량** — MP4 27.7 MB. 첨부 칸 한도(5 GB) 안입니다
5. **출시 버전과의 차이** — 2026-10-29 프로토타입(0.1.0) 기준입니다. 결제 · 광고 · 로그인 · 랭킹 · 사운드 등이 추가되거나 내용이 바뀌면 다시 확인해야 합니다
6. **빌드 기준 소스** — 커밋하지 않은 변경(앱인토스 SDK 연동)이 있는 상태에서 빌드했습니다. 게임 화면 · 규칙과 관련된 변경은 아닙니다
7. 신청 주체 · 수수료 등 행정 절차는 `docs/APPS_IN_TOSS.md` 2장 참고
